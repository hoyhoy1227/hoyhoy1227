## 01 · [한국어 → 한국수어(KSL) Gloss](projects/ksl-gloss.md)

한국어 문장을 수어 단어의 글 표기인 Gloss로 바꾸는 모델을 개발했습니다. 어떤 문법이 쓰였는지도 문법서 근거와 함께 설명합니다.

> **참여 역할** · 데이터 수집·정리 · 모델 추가 학습  
> X:AI 학회 팀 프로젝트

- **다른 문장을 넣어도 같은 단어만 나옴** · 초기 모델은 ‘지시1’ 같은 단어를 반복했습니다. 학습한 문장을 외운 것인지, 새 문장도 바꿀 수 있는지 나눠 확인했습니다. 이후 pko-T5에 LoRA와 출력층 학습을 적용했습니다.
- **입력에 없는 인물이 등장** · 문장에 없던 ‘할아버지1’이 나왔습니다. 표기가 맞는지와 입력의 뜻을 담았는지를 따로 살피고, 빠지거나 새로 생긴 의미를 기록했습니다.
- **새 자료에 맞춰 학습을 보완** · 2024 자료로 추가 학습한 v4를 만든 뒤, 2025 문장까지 학습 범위를 넓혔습니다. 입력 주석과 자료별 학습 비중, 학습 방식을 바꿔 v8로 발전시켰습니다.

[번역 예시·개발 과정·평가 결과](projects/ksl-gloss.md)

## 02 · [사기방지위원회](projects/whatfraud.md)

AI 캐릭터와 실시간으로 대화하며 스마트폰 금융사기를 체험하는 웹 게임입니다. 내가 어떻게 반응하고 대처했는지, 선택에 맞춘 보고서로 돌아봅니다.

> **참여 역할** · 기획 · 기능·스토리 구성 · Suno 음악 작업  
> 2인 공동 개발

- **AI 캐릭터에게 직접 묻기** · 지인 사칭·투자 권유·피해 회복 사칭을 만납니다. 주요 대화 장면에서 질문하거나 게임 속 기록을 보내면, AI가 인물과 상황에 맞게 답합니다.
- **확인하고 행동하기** · 연락처·돈을 받을 사람·안내 자료를 비교하고, 보류·차단·가상 송금 등을 선택합니다.
- **내 선택에 맞춘 보고서** · 단서를 언제 확인했고 어떻게 행동했는지 짚어 줍니다. ‘확인하겠다’고 답한 뒤 송금했다면 말과 행동이 달랐던 지점도 보여 줍니다. 선택 직전으로 되감아 다른 대응도 연습할 수 있습니다.

## 03 · [증권사 텍스트 데이터 분석](projects/financial-text-analysis.md)

국내 5개 증권사의 뉴스·공식 블로그·종목토론방에서 회사별 주제와 게시글 반응을 비교했습니다.

> **참여 역할** · 블로그 데이터 수집 및 분석, 종목토론방 데이터 분석  
> 4인 팀

- **블로그에서 다룬 주제** · 반복해서 등장하는 내용을 34개 주제로 묶었습니다. ‘미국’이 들어간 글은 키움 635/708개(89.69%), 삼성 1,960/3,357개(58.39%)였습니다.
- **종목토론방에서 나온 이야기** · 삼성은 배당과 단기 주가, 미래에셋은 제목·본문의 스페이스X와 댓글의 공매도 언급이 눈에 띄었습니다. 긍정·부정 표현과 추천·비추천·댓글 수도 살폈습니다.
- **게시글에 대한 반응** · 5개 회사 모두 추천이 비추천보다 많은 글이 절반을 넘었습니다. 회사별 비율은 52.02~68.48%였습니다.

수집한 글 기준이며, 회사마다 수집 기간과 게시량이 다릅니다.

[분석 방법·전체 결과](projects/financial-text-analysis.md)

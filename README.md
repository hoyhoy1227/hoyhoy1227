## 01 · [한국어 → 한국수어(KSL) Gloss](https://github.com/molba2see/adv-pj-a/tree/llm2-v4-to-v8-improvements)

한국어 문장을 수어 단어의 글 표기인 Gloss로 바꾸는 모델을 개발했습니다. 어떤 문법이 쓰였는지도 문법서 근거와 함께 설명합니다.

> **참여 역할** · 데이터 수집·정리 · 모델 추가 학습  
> X:AI 학회 팀 프로젝트
> **활동 기간** · 2026.07 ~ 2026.08

### 한국어와 수어는 어순이 어떻게 다를까

| 한국어 문장 | 한국수어 Gloss · 문법서 예시 |
| --- | --- |
| **왜** 아직 도착하지 않았나요? | [도착하다] [아직] **[왜]** |

한국어 예시에서 앞에 있던 ‘왜’가 수어 예시에서는 문장 끝에 옵니다. 눈썹을 올리고 눈을 크게 뜨는 표정도 의문을 나타냅니다. 한국어 문장은 예문의 뜻을 풀어 썼습니다. [국립국어원 《2020 한국수어 문법 연구》 90쪽](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=207&report_seq=1042)

### 모델이 바꾼 문장과 함께 제공하는 설명

| 한국어 입력 | 모델의 Gloss 출력 |
| --- | --- |
| 친구가 같이 가자고 말했어요. | `친구1 함께1 가다1 말하다1` |

직접 만든 문장의 실험 기록입니다. ‘친구가 말했다’는 인용과 ‘같이 가자’는 제안을 찾고, 문법서 3.4절 ‘청유문’ 175쪽을 근거로 보여 줍니다. 문장에서 부정·의문 같은 표현을 찾아 관련 문법서 항목과 쪽수를 제공하는 기능도 만들었습니다. [모델 출력과 문법 설명 기록](https://github.com/molba2see/adv-pj-a/tree/llm2-v4-to-v8-improvements/llm#문법-설명-계층-개선)

### 입력에 없던 단어도 나왔다

입력은 실제 오류를 설명할 수 있는 비슷한 문장으로 바꿨습니다. 출력은 당시 기록의 일부입니다.

| 입력 예시 → 관찰된 출력 조각 | 문제와 점검한 내용 |
| --- | --- |
| “주말에 전시를 보러 갈래요.” → `지시1` | 초기 KE-T5에서 문장과 무관한 한 단어만 나왔습니다. 학습 문장을 외운 것인지, 새 문장도 바꿀 수 있는지 나눠 확인했습니다. |
| “동료가 없어 혼자 점심을 먹었어요.” → `할아버지1` | 초기 KE-T5에서 입력에 없는 인물이 등장했습니다. 표기가 맞는지와 입력의 뜻을 담았는지를 따로 살폈습니다. |
| “손짓의 뜻을 설명해 줄래요?” → `제스처 제스처` | pko-T5 v4에서 번호가 빠지고 같은 단어가 반복됐습니다. 남은 오류를 기록하고 다음 학습에서 살펴볼 항목으로 삼았습니다. |

### 모델을 만들고 학습 범위를 넓힌 과정

1. **변환 모델 개발** · 초기 출력 문제를 살펴본 뒤 pko-T5에 LoRA를 적용하고, 결과 단어를 고르는 출력층도 학습했습니다. 같은 한국어 문장이 학습과 평가에 겹치지 않도록 나눴습니다. 번호가 붙는 자료와 번호 없는 자료는 나눠 처리했습니다.
2. **v4 개발** · 기존 번호형 모델에 NIKL 2024 자료를 더해 추가 학습했습니다. 평가를 거쳐 2024·2025 자료를 처리하는 공통 번호형 모델로 선택했습니다.
3. **v8 개선** · 2025 문장까지 학습 범위를 넓혔습니다. 2024 학습 문장의 주석을 정리하고, 2024 입력의 주석과 자료별 비중, 번호 보정을 함께 정리했습니다. 실험 기록에서 변환 오류가 줄었지만, 모든 종류의 오류가 해결된 것은 아닙니다.

NIKL 출처는 국립국어원 모두의 말뭉치 **「한국수어-한국어 병렬 말뭉치」**(2024·2025)입니다.

[모델 개발·평가 조건·전체 실험 기록](https://github.com/hoyhoy1227/hoyhoy1227/blob/main/projects/ksl-gloss.md) · [오류와 대응](https://github.com/hoyhoy1227/hoyhoy1227/blob/main/projects/ksl-gloss-errors.md) · [활용 데이터 출처](https://kli.korean.go.kr/corpus/)

## 02 · [사기방지위원회](https://github.com/hoyhoy1227/whatfraud)

AI 캐릭터와 실시간으로 대화하며 스마트폰 금융사기를 체험하는 웹 게임입니다. 내가 어떻게 반응하고 대처했는지, 선택에 맞춘 보고서로 돌아봅니다.

> **참여 역할** · 기획 · 기능·스토리 구성 · Suno 음악 작업  
> 2인 공동 개발
> **활동 기간** · 2026.08 ~ 2026.09

### AI와 대화하고 대응 고르기

지인의 이름으로 온 부탁 → 투자 자료방의 안내와 추가 비용 요구 → 피해를 되찾아 주겠다는 연락으로 이어지는 세 상황을 만납니다. 주요 대화 장면에서 직접 질문하거나 게임 속 기록을 보내면, AI 캐릭터가 인물과 상황에 맞게 답합니다.

연락처·돈을 받을 사람·안내 자료를 비교하고, 확인·보류·차단·가상 송금 등을 선택합니다.

**질문하기 → 답변과 기록 비교 → 대응 선택 → 맞춤 보고서 → 다른 대응 연습**

### 내 선택에 맞춘 보고서

무엇을 먼저 확인했는지, 가상 송금했는지, 증거를 남겼는지를 바탕으로 잘한 대응과 주의할 점을 짚어 줍니다.

| 플레이에서 한 말과 행동 | 보고서에서 돌아볼 내용 |
| --- | --- |
| ‘확인하겠다’고 답한 뒤 가상 송금 | 말과 행동이 달랐던 지점 |
| 단서를 확인하거나 증거를 남긴 기록 | 무엇을 언제 확인하고 어떻게 대응했는지 |

보고서는 플레이 기록과 정해진 분석 규칙으로 구성합니다. 선택 직전으로 되감아 다른 대응을 해 보고, 원래 결과와 비교할 수 있습니다.

### 플레이 중 발견한 대화 오류

실제 관찰한 오류와 보완 내용입니다. 일부 보완은 실제 응답 재확인이 필요합니다.

| 입력·상황 | 생긴 문제 | 고친 내용 |
| --- | --- | --- |
| 사칭 연락을 실제 준호에게 알림 | 준호 본인과 대화 중인데 다른 연락처로 다시 확인하라고 답함 | 캐릭터가 아는 사실과 플레이어가 이미 한 행동을 답변에 반영 |
| 지수에게 ‘수익 인증 글’을 첨부해 전송 | 화면에서 고른 첨부를 서버가 거절해 답변이 막힘 | 화면과 서버가 같은 첨부 목록을 쓰도록 맞춤 |
| 정상적인 보완 대사를 사용 | 문장 수와 물음표 제한에 걸려 답변이 막힘 | 표현 검사와 게임 진행 검사를 나누고, 실패할 때 쓸 대사도 수정 |

AI는 캐릭터의 답변을 만들고, 게임 엔진은 사건·잔액·결말을 관리합니다.

## 03 · 증권사 텍스트 데이터 분석

국내 5개 증권사의 공식 블로그와 종목토론방을 분석해, 회사별 콘텐츠 주제와 투자자 반응을 비교했습니다.

> **참여 역할** · 블로그 수집·주제 분석, 종목토론방 글·반응 분석  
> **활동 기간** · 2026.03 ~ 2026.06 · 4인 팀 수업 프로젝트

### 분석 과정

- **블로그** · 수집한 글에서 반복 문구와 불용어를 정리하고, 단어 빈도·TF-IDF·토픽 모델링으로 회사별 주제를 비교했습니다.
- **종목토론방** · 주요 단어와 감성을 분석하고, 추천·비추천·댓글을 집계했습니다. 주가·기업 이슈와 시간대별 반응도 함께 살폈습니다.

### 핵심 결과

| 분석한 내용 | 확인한 결과 |
| --- | --- |
| 블로그 주제 | 삼성은 시장·경기, 미래에셋은 산업·기업, NH는 자산관리 주제가 두드러졌습니다. |
| 주가·기업 이슈와 반응 | 삼성은 강한 추천 글 비중이, 한화는 비추천 글 비중이 5개사 중 가장 높았습니다. 주가 상승 구간과 두나무·비트코인 이슈를 함께 살폈습니다. |
| 글의 내용과 반응 | 추천이 더 많은 글은 5개사 모두 절반을 넘었습니다. 하지만 반응이 많은 글의 사전 기반 평균 감성 점수는 모두 0보다 낮았습니다. |

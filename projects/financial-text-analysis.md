# Case Study 03 · 증권사 텍스트 데이터 분석

**뉴스·회사 블로그·종목토론방을 연결한 탐색적 비교 분석**

## 문제와 분석 범위

같은 증권사를 다루더라도 뉴스, 회사 블로그, 투자자 종목토론방은 서로 다른 관점을 담습니다. 국내 5개 증권사의 자료를 수집·전처리하고, **매체별 핵심 주제·텍스트 감성·이용자 반응을 구분해 비교**했습니다.

대상은 삼성증권·미래에셋증권·키움증권·NH투자증권·한화투자증권입니다. 결과는 수집 자료에 대한 탐색적 분석이며, 회사의 실제 전략·시장 전체 투자심리·주가 예측 성능을 검증한 결과가 아닙니다.

## 수집과 전처리

| 자료 | 원본에 기재된 수집·처리 내용 |
| --- | --- |
| 뉴스 | 네이버 API로 증권사별 1,000건 수집. 네이버 뉴스 링크가 있는 자료의 링크·제목·본문·댓글을 CSV로 저장하고 분석에는 본문만 사용 |
| 블로그 | 5개 증권사의 리포트·콘텐츠 비교. 아래 문서 수는 원본의 미국 관련 글 비교에 사용된 집합이며, 동일 기간·중복 제거 조건은 미제시 |
| 종목토론방 | Selenium, XPath·CSS_SELECTOR로 탐색. 증권사별 1,500건(총 7,500건) 목표에서 클린봇 제외 글을 고려해 75→80페이지로 확대. 원문상 실제 수집량은 각 1,560건 이상 |

종목토론방에서는 날짜·제목·본문·추천·비추천·댓글 수·댓글을 수집했습니다. 제목과 본문을 결합하고, 워드클라우드에서는 제목·본문과 댓글을 나누어 살폈으며 감성분석에서는 함께 활용했습니다. 날짜에서 시간과 세션을 파생해 반응량도 비교했습니다.

- **기본 정제:** 증권사명·광고·특수문자·줄바꿈·불필요한 숫자와 단위를 정리하고 대소문자·공백을 통일했습니다. 블로그의 반복 문구도 제거했습니다.
- **토큰화:** Kiwi로 명사·영어 토큰을 추출했습니다. 블로그에서는 영어를 대문자로 통일하고 2글자 이상 토큰을 사용했습니다.
- **분석 목적별 불용어:** 워드클라우드에서는 ‘투자·분석·수요’처럼 회사 간 차이를 가리는 공통 단어를 추가 제거했습니다. 감성분석에서는 ‘상승·하락·급등·급락’ 등의 감성 신호를 보존했습니다.
- **도메인 보완:** 종목토론방의 오타·사투리 교정과 고유 이슈 단어 보존을 반영했습니다. KNU 감성어 사전에 주식 도메인 어휘와 개별 점수 재정의를 추가했습니다. 이 보완의 정확도 개선을 측정한 별도 정답 평가셋은 원문 본문에서 확인되지 않습니다.

삼성은 시장·매크로 코멘터리, 미래에셋은 산업·기업 및 다양한 해외시장, NH는 자산관리, 한화는 ETF·수출, 키움은 개인투자자 대상 종목·이슈 콘텐츠가 두드러졌다는 원본 해석을 정리했습니다.

원문에는 삼성 블로그 운영 중단 시점과 키움의 2024~2025년 콘텐츠 등 서로 다른 시기 정보가 있습니다. **회사별 기간·게시량·포맷이 달라 원시 건수를 동일 조건의 관심도 순위로 읽을 수 없습니다.** ‘미국 관련’ 분류의 정확한 검색식도 원문에 명시되어 있지 않습니다.

## 감성·추천 반응·시간대 분석

**텍스트 감성**

KNU 기반 사전을 주식 도메인에 맞게 보완하고 제목·본문·댓글을 분석했습니다. 원문은 중립이 절반 이상이고 부정 비율이 긍정보다 약간 높다고 설명합니다. NH의 긍정·부정 비율은 비슷하고, 미래에셋의 부정 비율이 가장 높으며, 키움의 긍정 비율이 가장 낮다고 기재되어 있습니다.

긍정어는 상승 기대·수익·가치, 부정어는 하락·손실·체념·불만과 연결했습니다. 회사별 긍정·부정 상위 10개 감성어에서 뚜렷한 차이를 확인하지 못했다는 결과도 포함합니다. 키움의 낮은 감성 점수를 주가 급등락과 연결한 설명은 원문의 추정이며 인과 검증 결과가 아닙니다.

**추천·비추천 반응**

| 대상 | 지표 | 원문 본문 기재값 |
| --- | --- | --- |
| 키움증권 | 추천·비추천 분석의 중립 비율 | 32.99% |
| 삼성증권 | 강한 추천 우세 비율 | 31.71% |
| 한화투자증권 | 강한 비추천 우세 비율 | 5.37% |
| 미래에셋증권 | 추천 우세 / 비추천 우세 비율 | 68% / 20% |

위 비율은 **텍스트 감성의 긍정·부정 비율과 다른 지표**입니다. ‘추천 우세’는 게시글에 대한 이용자 동의·반응이며 긍정 감정을 뜻하지 않습니다. 반응 점수의 정확한 산식, ‘강한 우세’ 임계값과 각 비율의 분모는 본문에 제시되지 않아 재계산·성능 비교를 하지 않았습니다.

**시간대와 고반응 글**

- 총반응량은 장 시작 직후 **9~10시**, 장 마감 전후 **14~15시**에 집중된다고 원문은 설명합니다.
- **글당 평균 반응량은 야간이 가장 높다**고 기재되어 있습니다. 총반응량과 글당 평균은 분모가 다른 비교입니다.
- 회사별 고반응 글의 평균 감성 점수는 모두 0 미만이라고 기재되어 있어 부정적인 글도 높은 반응을 얻을 수 있음을 보여줍니다.
- 키움의 반응량이 적은 이유는 원문에 확인 예정 메모로 남아 있습니다. 야간의 높은 반응량에 대한 행동 설명 역시 작성자의 해석이며 검증된 원인으로 제시하지 않았습니다.

## 검증 범위·개인 기여·재현 조건

- 이 문서는 사용자가 제공한 원본 Notion 요약의 **전체 본문·표**를 대조한 사례 정리입니다. 원본의 이미지 70개는 이미지 서버 연결 문제로 개별 코드·차트를 재확인하지 못했습니다. 이미지에만 있는 수치·코드는 옮기지 않았습니다.
- 원시 CSV·실행 노트북·수집 로그를 재실행한 결과가 아니며, 위 수치와 비율은 별도 표시된 합산값을 제외하고 원문 기재값입니다.
- 뉴스 필터 후 최종 분석 건수, 전체 자료의 중복 제거 기준, 회사별 정확한 수집 기간, 미국 관련 글의 분류식은 추가 확인이 필요합니다.
- 워드클라우드·토픽·감성·추천 반응은 서로 다른 측정입니다. 회사의 전략·서비스 품질·주가에 대한 인과 결론이나 예측 정확도로 제시하지 않습니다.
- KNU 점수 보강은 해당 프로젝트의 사용자 정의입니다. 공식 사전의 오류나 검증된 정확도 향상으로 표현하지 않았습니다.
- 토픽 모델 설정·품질 평가와 추천 점수 산식·구간 정의가 빠져 있어 완전한 재현을 위해 원본 코드와 로그가 필요합니다.

# Case Study 03 · 증권사 텍스트 데이터 분석

**뉴스·회사 블로그·종목토론방을 연결한 탐색적 비교 분석**

## 문제와 분석 범위

같은 증권사를 다루더라도 뉴스, 회사 블로그, 투자자 종목토론방은 서로 다른 관점을 담습니다. 국내 5개 증권사의 자료를 수집·전처리하고, **매체별 핵심 주제·텍스트 감성·이용자 반응을 구분해 비교**했습니다.

대상은 삼성증권·미래에셋증권·키움증권·NH투자증권·한화투자증권입니다. 결과는 수집 자료에 대한 탐색적 분석이며, 회사의 실제 전략·시장 전체 투자심리·주가 예측 성능을 검증한 결과가 아닙니다.

4인 팀 수업 프로젝트입니다. 아래 구현은 원본 PDF·노트북·저장 데이터로 확인한 **팀 공동 결과**이며, 기능별 개인 담당 범위는 원본에서 분리되지 않습니다.

## 수집과 전처리

**검색 목표와 실제 저장량을 구분했습니다.** 뉴스는 증권사별 네이버 API 검색 결과를 최대 1,000개 요청한 뒤, 네이버 뉴스 링크와 본문 수집 성공 조건을 적용했습니다. 최종 저장 뉴스는 5,000건이 아니라 **1,286행(고유 링크 1,285개)**입니다.

| 증권사 | 뉴스 저장 행 | 블로그 저장 행 | 종목토론 저장 행 |
| --- | --- | --- | --- |
| 삼성증권 | 227 | 3,357 | 1,583 |
| 미래에셋증권 | 268 | 1,787 | 1,579 |
| NH투자증권 | 272 | 702 | 1,563 |
| 한화투자증권 | 217 | 7,725 | 1,582 |
| 키움증권 | 302 | 708 | 1,573 |
| 합계 | 1,286 | 14,279 | 7,880 |

- **뉴스:** API 검색 정렬은 `sim`입니다. Selenium으로 링크·제목·본문·댓글을 수집하고, 워드클라우드는 본문을 사용했습니다.
- **블로그:** 회사별 수집 코드를 사용했습니다. 제목과 본문을 결합하며, 회사별 기간·문서 형식·본문 누락이 다릅니다.
- **종목토론:** Selenium·XPath·CSS_SELECTOR로 증권사별 1,500건을 목표로 탐색했습니다. 클린봇 제외 글을 고려해 75→80페이지로 늘렸고, 날짜·제목과 본문·추천·비추천·댓글 수·댓글을 저장했습니다.
- **워드클라우드:** 뉴스·토론방은 Kiwi로 명사·영어 등을 추출하고 고유 이슈 사용자 사전과 오타 교정을 적용했습니다. 블로그는 영어 대문자 통일·2글자 이상·사용자 불용어를 적용했습니다.
- **목적별 분리:** 워드클라우드의 공통어 제거, soynlp 기반 토픽용 토큰화, 감성 신호를 보존하는 KNU 분석은 서로 다른 전처리입니다. 모든 분석을 동일한 Kiwi 파이프라인으로 처리한 것은 아닙니다.

건수는 제공된 CSV의 저장 행 기준입니다. 원본 분석에 남아 있는 중복을 임의로 제거해 결과를 바꾸지 않았으며, 중복·누락·날짜 조건은 마지막 절에 적었습니다.

## 블로그 토픽 모델링

**실제 구현:** 반복 문구·숫자 등을 정리한 전체 블로그 말뭉치에 `soynlp LRNounExtractor_v2`를 적용하고, 명사 점수 0.5 이상·빈도 2~5,000·길이 2 이상 조건으로 `LTokenizer` 사전을 구성했습니다. 회사별 TF-IDF와 scikit-learn LDA를 학습하고 pyLDAvis HTML 및 문서별 토픽 확률 CSV를 저장했습니다.

| 단계 | 원본 코드 설정 |
| --- | --- |
| TF-IDF | `max_features=700`, `max_df=0.3`, `sublinear_tf=True`, 사용자 tokenizer |
| LDA | `random_state=42`, `max_iter=30`, `topic_word_prior=0.01`, `doc_topic_prior=0.05` |
| 토픽 수 | 삼성 9 · 미래에셋 7 · NH 5 · 한화 9 · 키움 4, 총 34개 |
| 문맥 확인 | spaCy·textacy KWIC로 ‘리니지·아파트·규제’ 주변 문맥 확인 |

아래 값은 **저장된 pyLDAvis의 토픽 비중(시각화의 토큰 가중 분포)**입니다. 해당 토픽이 최우세인 문서의 비율이나 문서별 확률의 단순 평균과 다릅니다. 번호는 pyLDAvis 표시 순서이며 원본 LDA의 열 순서는 재정렬됩니다. 주제명은 PDF 작성자의 해석입니다. 소수 첫째 자리 값은 저장 HTML에서 반올림했습니다.

## 감성·추천 반응·시간대 분석

### 텍스트 감성

KNU JSON 14,843개 항목(고유 표제어 14,841개)을 읽고 중복 표제어는 절댓값이 큰 점수를 선택했습니다. 주식 도메인 사전·점수 보완을 더하고 ‘지지’를 제외했습니다. **제목·본문·댓글**을 합쳐 Kiwi 오타·사투리 보정, 품사 필터, 용언 기본형·2~3그램 후보를 만든 뒤 문서별 후보 중복을 제거해 사전 점수를 합산했습니다.

- 점수 > 0: 긍정, < 0: 부정, = 0: 중립으로 분류했습니다.
- 저장 출력은 전체 7,880행 중 **긍정 1,742 · 중립 4,050 · 부정 2,088**입니다. 0점은 매칭된 감성어가 없거나 양·음 점수가 상쇄된 경우도 포함하므로 실제 중립 감정의 정답으로 볼 수 없습니다.
- NH의 긍정·부정 건수는 비슷하고, 미래에셋의 부정 비율이 가장 높으며, 키움의 긍정 비율이 가장 낮습니다. 회사별 상위 감성어의 차이가 뚜렷하지 않았다는 원본 관찰도 함께 남겼습니다.
- 낮은 PER·고객센터 불만 등과 감성을 연결한 PDF의 설명은 작성자의 가설입니다. 시장 자료와 대조해 인과를 입증한 결과는 아닙니다.

### 보조 분류 실험과 평가 조건

KNU 점수로 만든 긍정·부정 **의사라벨**에 TF-IDF(1~2그램, `min_df=2`)와 Logistic Regression(`max_iter=1000`)을 학습했습니다. 중립은 제외하고 80:20 분할(`random_state=42`, 가능한 경우 stratify)을 사용했습니다.

저장 출력은 테스트 766개에 **정확도 88.25%**, 혼동행렬 `[[389, 29], [61, 287]]`입니다. **사람이 판정한 감성 정답에 대한 정확도가 아니라 사전 의사라벨과의 일치도**입니다. 더욱이 TF-IDF를 전체 데이터에 먼저 적합한 후 분할하여 어휘·IDF 정보가 평가셋에서 유입되는 문제가 있습니다. 독립 검증 성능이나 개선 입증 수치로 내세우지 않습니다.

### 추천·비추천 반응

- `score = recommend - disrecommend`: 양수는 추천 우세, 음수는 비추천 우세, 0은 동률입니다.
- 강한 추천 우세는 `score >= 5`, 강한 비추천 우세는 `score <= -5`입니다.
- 분모는 각 회사의 **유효 날짜가 있는 저장 게시글 수**이며 이번 자료는 7,880행 모두 유효합니다. 강한 우세는 해당 우세 집합의 부분집합입니다.

| --- | --- | --- | --- | --- | --- | --- |

추천 우세는 게시글에 대한 이용자 반응이며 **긍정 감정 비율과 다른 지표**입니다. 위 비율은 원본 코드의 산식으로 CSV에서 재계산했습니다.

### 시간대와 고반응 글

`engagement = recommend + disrecommend + comment_count`를 사용했습니다. 원본 세션 구간을 유지해 재계산한 결과입니다.

| 비교 단위 | 가장 큰 구간 | 반응 합계 | 게시글 수 | 글당 평균 |
| --- | --- | --- | --- | --- |
| 1시간별 합계 | 09시 | 4,932 | 1,161 | 4.25 |
| 세션별 합계 | 11~13시 | 11,391 | 1,974 | 5.77 |
| 세션별 글당 평균 | 19~23시 | 7,563 | 737 | 10.26 |

세션 길이와 표본 수가 달라 총량과 평균을 함께 봐야 합니다. 1시간별 평균은 03시가 23.55로 가장 크지만 게시글이 11개뿐입니다. ‘야간 세션 평균이 가장 높음’을 ‘모든 시간 단위에서 야간이 가장 높음’으로 확대하지 않습니다.

고반응 기준은 전체 `engagement`의 90% 분위수 **14 이상**입니다. 동점 포함 **842행(10.69%)**이므로 정확히 상위 10%를 잘라낸 집합이 아닙니다. 회사별 고반응 글의 평균 감성 점수는 저장 출력상 모두 음수입니다. 이 단계는 **제목·본문만**, 기본 사전에서 ‘지지’ 제외·‘일류’ 점수 보정 등을 적용해 분석하므로 댓글과 금융 확장 사전을 쓰는 전체 감성분석과 직접 비교할 수 없습니다. PDF의 낮은 반응량 원인 설명도 검증된 인과 대신 가설로 남겼습니다.

# 한국어 → 한국수어(KSL) Gloss · 오류와 대응

초기 KE-T5와 pko-T5 v4의 개발 기록, 저장된 예측, 당시 터미널 기록을 바탕으로 정리했습니다. 입력은 실제 오류를 설명할 수 있는 유사 문장으로 바꾼 예시가 포함될 수 있으며, 출력은 당시 기록의 일부입니다. [v8 실험과 평가 결과](ksl-gloss.md)와 [보조 검증 기록](../verification/2026-11-01/README.md)을 함께 참고할 수 있습니다.

## 입력과 출력의 차이

| 입력 예시 → 관찰된 출력 조각 | 문제와 점검한 내용 |
| --- | --- |
| “주말에 전시를 보러 갈래요.” → `지시1` | 초기 KE-T5에서 문장과 무관한 한 단어만 나왔습니다. 학습 문장을 외운 것인지, 새 문장도 바꿀 수 있는지 나눠 확인했습니다. |
| “동료가 없어 혼자 점심을 먹었어요.” → `할아버지1` | 초기 KE-T5에서 입력에 없는 인물이 등장했습니다. 표기가 맞는지와 입력의 뜻을 담았는지를 따로 살폈습니다. |
| “손짓의 뜻을 설명해 줄래요?” → `제스처 제스처` | pko-T5 v4에서 번호가 빠지고 같은 단어가 반복됐습니다. 남은 오류를 다음 학습에서 살펴볼 항목으로 삼았습니다. |

입력의 뜻을 담았는지와 Gloss 표기가 맞는지를 따로 살폈습니다. 초기 KE-T5와 pko-T5 v4는 서로 다른 실험 단계입니다.

## 추론이 시작되지 않은 경우

초기 어댑터를 불러올 때 `lm_head`의 체크포인트 크기 `[64128, 512]`와 당시 기반 모델 크기 `[64100, 512]`가 달라 `size mismatch`로 중단된 터미널 기록이 있습니다.

- **문제:** 번역 결과가 틀린 것이 아니라 모델을 불러오는 단계에서 오류가 발생했습니다.
- **대응:** 학습 당시 토크나이저·확장 어휘 크기로 embedding을 맞춘 뒤 어댑터를 읽도록 로딩 순서를 고쳤습니다.

## v4 저장 예측에서 확인한 오류

제공된 최종 패키지의 `pko_t5_base_ksl_nikl_2024_adapter_v4/repeat_safe_general_700` 저장 예측을 로컬에서 확인했습니다. 번호형 경로에서 **`한글지문자 문자지문자`**, **`제스처 제스처`** 같은 생성이 남아 있었습니다.

- **문제:** 번호형 표기 이탈과 짧은 반복이 남아 있었습니다.
- **대응:** 데이터 정규화·중복 제거·문장 그룹 분할과 학습 구성을 함께 바꾸며 재검토했습니다. 특정 한 변경이 오류를 모두 해결했다고 단정하지 않았습니다.
- **한계:** 이번 기록은 저장 예측을 확인한 결과이며, 모델을 새로 실행한 결과가 아닙니다.
